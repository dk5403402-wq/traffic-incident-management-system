# Traffic Incident Management System

A simple website made to report and view traffic incidents. This project was made for my course CSE326 using HTML and CSS.

## Purpose
Traffic incidents like accidents and road blocks need to be reported quickly. This website gives a simple way to submit an incident and see the report details.

## Tools Used
- HTML
- CSS
- GitHub Pages (for hosting the website)

## Project Files
- index.html : Home page of the website
- report.html : Page that shows the incident report
- submit.html : Page to submit a new incident
- style.css : Styling for all the pages

## How to Run
1. Download or clone this repository.
2. Open index.html in any web browser.

## Live Website
https://dk5403402-wq.github.io/traffic-incident-management-system/

## How I Built It
I planned the pages first, then wrote the structure in HTML and the design in CSS. I kept the design simple so that it is easy to read on any screen.

A working multi-page website that is live online through GitHub Pages.
